A one-line laugh for make.fun's "The One-Line Laugh" bounty: a single funny sentence of at most 200 characters, written to `entry.txt` by a small deterministic Node program. No network, no randomness — two runs produce byte-identical output.

The line:

> The recipe said 'serves four', so I ate it alone and learned it serves one liar.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the line to `out/entry.txt` (or `/output/entry.txt` when `MAKEFUN_OUTPUT_DIR` is unset). The program throws unless the line is 1–200 characters, a single line, and trimmed.
